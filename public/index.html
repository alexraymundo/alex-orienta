Un acompañamiento pensado para decisiones reales.

La experiencia está diseñada para que cada proceso tenga un objetivo claro, seguimiento y herramientas útiles.

01

PROCESO

Cómo funciona NORTIA.

01 Solicitud de cita

La persona comparte sus datos básicos, motivo general y horario preferido.

02 Primera sesión

Se define contexto, objetivo y el punto de partida del proceso.

03 Mapa vocacional / seguimiento

Se registran intereses, fortalezas, dudas abiertas y próximos pasos.

04 NORTIA Reflexión

Herramienta supervisada para trabajar preguntas y ejercicios entre sesiones.

HERRAMIENTA COMPLEMENTARIA

NORTIA Reflexión

Un espacio de apoyo para ordenar ideas, comparar opciones y continuar ejercicios de reflexión dentro del proceso definido por Alex.

  • No sustituye atención profesional.
  • No diagnostica ni prescribe.
  • Está enfocada en reflexión y claridad.
SOBRE ALEX

Una experiencia más profesional, cercana y ordenada.

Alex combina orientación, seguimiento y herramientas digitales para dar estructura a cada proceso y facilitar decisiones importantes.

El objetivo es que cada persona pueda identificar qué necesita trabajar, registrar avances y llegar a cada sesión con mayor claridad sobre sus siguientes pasos.

SEGUIMIENTO PERSONALIZADO

Cada proceso es diferente.

Objetivos, sesiones, ejercicios y próximos pasos se organizan de acuerdo con las necesidades de cada persona para dar continuidad al proceso.
